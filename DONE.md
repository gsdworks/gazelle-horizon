2026-08-11 — LEARNING, SMART COLLECTIONS ON METAFIELDS — THE STANDARD PATTERN FOR THIS STORE. Smart collection metafield conditions support ONLY "is equal to". `list.single_line_text_field` IS supported, and an equals condition matches if ANY entry in the list matches. The metafield definition must have the `smartCollectionCondition` capability enabled or it cannot be used in a rule at all. Because prefix-matching is impossible, a derived field is the only route — hence `thema_top`. Reuse this pattern for any future taxonomy collection: derive the exact value you want to match, don't try to match a substring.
